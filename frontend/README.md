# Raritone Web Frontend

This Vite/React frontend now includes a Figma-inspired screen board based on the provided screenshots.

## Implemented visual flows
- Onboarding / curated fashion intro
- Login by mobile number
- OTP verification states
- Setup profile form
- Product home feed
- Product detail and AR try-on variant
- Virtual try-on method sheets
- 3D figure creation sheet
- VR headset flow
- Avatar wardrobe grid
- Profile dashboard
- Empty wardrobe / wishlist states
- Wishlist product grid

## Run locally
```bash
npm install
npm run dev
```
