# Raritone Web Frontend

This dependency-free web frontend is a lightweight reference board for the React Native app screens. It uses native HTML/CSS layout primitives and vector-like shapes only; it renders no captured image components.

## Implemented visual flows
- Splash and onboarding
- Authentication
- Home product feed
- Body scan
- Avatar profile
- Virtual try-on
- Product detail
- Profile dashboard

## Run locally
```bash
npm run dev
```

No package installation is required for the frontend preview.
